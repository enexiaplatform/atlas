# Servicebio Vietnam evaluation

Open the local Atlas page and choose **Open synthetic Servicebio pilot**. All named institutions, source material and comparisons in this exercise are fictional. Unknown prices, SKUs, specifications and demand should stay unknown. The new pack adds four records to the original twelve on a fresh pilot. Existing workspaces retain their edits when setup runs.

| Try this | Expected result |
|---|---|
| Choose New asset → Workspace template → Product profile. Enter a training title and an application. | The scientific domain and relevant fields appear. Saving creates an unverified draft. Copy the browser address and refresh to reopen the record. |
| Open Intelligence database. Search for scanner and select Compare beside Digital slide scanner and Alternative slide scanner. | Inspect aligned fields, missing values, verification and revisions. Export selected downloads the selected metadata. Click a title to inspect evidence, originals or links. |
| In Knowledge graph, search for Western blot workflow and select its row. Follow the membrane edge and return through the incoming link. | Instruments, reagents, consumables and a scientific application come from stored workspace edges. |
| Search for “phong nghien cuu” and select the Minh An lab. Follow its histology application to the scanner, competitor and GTM plan. | Unaccented text finds the Vietnamese title. The graph also connects the lab to its institution and market landscape. |
| Start a GTM assumptions or Scientific value proposition draft. Use Relationships to reference the existing landscape, product and comparison. | Each assumption remains an authored knowledge record and each outgoing link creates a revision. |
| Attach the supplied pilot/research-note.docx to a local draft. In Evidence & files, add a claim, source passage, supporting attachment and claim type. Submit via Governance → In Review. As reviewer, inspect the source before publishing. | Publication and factual verification are separate. A training document can support a claim about the exercise only. History shows the revisions. |
| In Knowledge assistant search for “archival microscopy”. Then try a phrase absent from the workspace. | The first result quotes the indexed DOCX passage and identifies its asset, source and revision. The second query reports missing support. |
| In the library import the supplied institutions.xlsx, confirm authorization and select Validate import. | The preview checks both rows before saving. Cancel leaves the library unchanged. Import records creates new drafts. Use the template for future authorized datasets only. |
| From Administration export the workspace, or export selected records from a comparison. | Files contain metadata under your signed-in permissions. Original documents require a separate authenticated download. |
